# Task Management System

## Project Description
Task Management System is a simple web application that helps users organize, manage, and track their daily tasks.

Users can create, edit, delete, and update tasks according to their progress.

## Project Information
- **Project Type:** Web Application
- **Methodology:** Scrum
- **Team:** Individual (Solo Project)
- **Level:** Beginner

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage

## Main Features
- Add new tasks.
- Edit existing tasks.
- Delete tasks.
- Update task status.
- Set task priorities.
- Save tasks using LocalStorage.

## Project Objectives
- Practice web development skills.
- Understand Scrum principles.
- Apply iterative development.
- Organize work using Sprints.
- Deliver a functional web application.

## Development Plan

### Sprint 1: User Interface
Create the basic HTML structure and CSS design.

### Sprint 2: Task Management
Implement adding, editing, and deleting tasks.

### Sprint 3: Task Organization
Add task statuses and priority levels.

### Sprint 4: Storage and Testing
Implement LocalStorage and test the application.
